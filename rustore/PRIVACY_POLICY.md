# Политика конфиденциальности Smart Wallet

Дата обновления: 4 июня 2026 года

Smart Wallet уважает конфиденциальность пользователей и обрабатывает только те данные, которые нужны для работы приложения.

## Какие данные обрабатываются

Приложение может обрабатывать следующие данные:

* номер телефона, имя и email, если пользователь указывает их при регистрации;
* данные банковских карт, добавленные пользователем в приложении, например название банка, название карты, последние четыре цифры и правила кэшбэка;
* данные операций и расходов, которые пользователь добавляет или подтверждает в приложении;
* техническую информацию о сетевом подключении, необходимую для работы с сервером;
* данные с камеры при сканировании QR-кода оплаты;
* данные NFC, если пользователь использует добавление карты через NFC.

Приложение не запрашивает полный номер банковской карты для хранения платежных данных и не выполняет реальные банковские платежи.

## Для чего используются данные

Данные используются для:

* регистрации и входа в аккаунт;
* отображения карт, истории операций и аналитики расходов;
* расчёта и подбора выгодного кэшбэка;
* работы финансового ассистента;
* улучшения удобства использования приложения.

## Где хранятся данные

Основные данные пользователя хранятся на сервере Smart Wallet. Приложение передаёт данные на сервер по сети для выполнения функций аккаунта, карт, операций, аналитики и ассистента.

## Передача третьим лицам

Данные пользователя не продаются третьим лицам. Передача данных возможна только если это требуется для работы приложения, выполнения закона или защиты прав пользователей и сервиса.

## Разрешения приложения

Приложение использует доступ к интернету для соединения с сервером Smart Wallet.

Доступ к камере используется для сканирования QR-кодов оплаты.

Доступ к NFC используется для удобного добавления карты, если пользователь сам запускает соответствующий сценарий.

Доступ к состоянию сети используется для корректной обработки ошибок подключения.

## Безопасность

Для авторизации используется токен доступа. Пользователь должен хранить данные своего аккаунта в безопасности и не передавать их другим людям.
