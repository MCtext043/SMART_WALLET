# SmartWallet — Умный финансовый кошелек

Современное Android-приложение для управления банковскими картами, транзакциями и оптимизации кэшбэка с поддержкой AI-ассистента.

## Возможности

* **Аутентификация:** Безопасная регистрация и вход по номеру телефона с использованием JWT.
* **Управление картами:** Добавление карт (ручной ввод или NFC-сканирование), настройка правил кэшбэка по категориям.
* **Транзакции и аналитика:** Учёт расходов, авторасчёт полученного кэшбэка, наглядные графики (MPAndroidChart).
* **AI-ассистент:** Встроенный чат-бот для финансовых советов и анализа текущих трат. Учитывает профиль пользователя и историю покупок.
* **Рекомендатель:** Подсказки по выбору наиболее выгодной карты перед оплатой в конкретной категории.

## Технологии

* **Язык:** Java 11
* **Архитектура:** MVVM, Repository pattern, LiveData
* **UI:** Material Components, RecyclerView, ViewPager2
* **Сеть:** Retrofit 2, OkHttp 4, Gson
* **Графики:** MPAndroidChart
* **SDK:** Min SDK 26 (Android 8.0), Target SDK 36

## Установка и запуск

1. **Клонирование проекта**
   ```bash
   git clone <url_репозитория>
   cd SmartWallet/mobile
   ```

2. **Настройка адреса API**
   В корне проекта `mobile` создайте или отредактируйте файл `local.properties`:
   ```properties
   api.base.url=http://ВАШ_IP_ИЛИ_ДОМЕН:8000/
   ```
   *Для локального тестирования на эмуляторе используйте `http://10.0.2.2:8000/`*

3. **Сборка проекта**
   ```bash
   ./gradlew assembleDebug
   ```
   Собранный APK-файл будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура проекта

* `ui` — Activity, Fragments, Adapters (пользовательский интерфейс)
* `viewmodel` — бизнес-логика экранов
* `network` — API-клиенты Retrofit, DTO-модели
* `model` — доменные модели
* `utils` — вспомогательные классы (TokenManager, форматирование валют, обработка ошибок)
* `nfc` — модуль чтения EMV-данных с банковских карт
